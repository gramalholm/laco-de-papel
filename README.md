# Laço de Papel

> Plataforma web de clubes do livro onde usuários criam grupos, convidam amigos, escolhem as obras de cada ciclo e registram suas leituras em conjunto.

**Status do projeto:** Em planejamento / estrutura inicial.

---

## Sobre o Projeto

O **Laço de Papel** é uma plataforma web desenvolvida para auxiliar clubes de leitura na gestão de suas leituras e participantes.

### Objetivo
Oferecer um espaço simples e organizado para grupos de leitura gerenciarem seus clubes, decidirem coletivamente o livro de cada ciclo e acompanharem o andamento das leituras.
